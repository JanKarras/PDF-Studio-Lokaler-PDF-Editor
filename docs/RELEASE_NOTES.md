PDF Studio 1.0.1 behebt das Verschieben von Seiten per Drag & Drop.

- Seiten können vor oder hinter andere Seiten gezogen werden.
- Eine blaue Einfügelinie zeigt die Zielposition.
- Mehrfachauswahl und Rückgängig funktionieren weiterhin.

**Installation:** PDF-Studio-Windows.zip vollständig in einen neuen Ordner entpacken und PDF-Studio/PDF-Studio.exe starten. Den Ordner _internal unverändert neben der EXE lassen.

Alle Funktionen und Lizenzbedingungen von Version 1.0.0 bleiben erhalten.
